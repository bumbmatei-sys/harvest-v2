# CW-11 — Campaign follow-up (filter, counts, team)

Founder scope choice (26 Nov 2026): "Filter + counts + campaign team".

## Delivered
- Migration `0115_campaign_followup_team`: table `campaign_followup_team` (RLS enabled and forced, no app grants) and owner/admin
  SECURITY DEFINER functions `followup_campaign_cases`, `followup_campaign_counts`, `followup_campaign_team`,
  `set_followup_campaign_team_member`. `followup_cases.campaign_id` stays unreadable to `harvest_app` (0048); eligibility uses
  `public.access_role(...)` (0113 guard).
- Server: `listFollowUpCases({ campaignId })` (keyset paging, same fields), `campaignFollowUpCounts`, `campaignFollowUpTeam`,
  `setCampaignFollowUpTeamMember` (idempotent, audited `followup.campaign_team.add` / `.remove`).
- API: `GET /api/workspaces/:id/followup-cases?campaignId=`; `GET|PATCH /api/workspaces/:id/campaigns/:campaignId/follow-up`.
- UI (owners/admins only): follow-up card on the campaign page (four counts, no names; team list with remove; add via the shared
  SearchableSelect; link to the filtered list). Follow-up list accepts `?campaign=`, keeps it across tabs and pages, offers
  "All campaigns", and lists the campaign team first among assignees.
- No new kit items: reuses Card, Button, Alert, SearchableSelect and DataTable. 44px tap targets on mobile; theme tokens only.

## Evidence (author-executed)
- `tests/integration/cw11-campaign-follow-up.test.ts`: 5 tests (list and paging, counts, team add/remove/audit, denials for
  member/viewer/stranger/other ministry, 404 for unknown campaign, no direct table access, RLS forced).
- `tests/unit/kit-pr6-follow-up.test.ts`: campaign query parsing and link round-trip. Full unit suite 1776/1776; typecheck clean.

## Intended scope notes
- Access is `followup:manage` in the Connect area. A collaborator with Connect manage but no Campaigns access can read counts and
  team for a campaign id they already know; they cannot list campaign ids. Accepted as intended scope.
- A team member whose role is later lowered to viewer stays on the team. It grants nothing, assignment re-checks eligibility, the
  follow-up list only orders eligible members first, and the card shows them as "No longer eligible" with a remove button.

## Not included
- Automatic assignment to the team, per-campaign notifications, counselor-facing campaign views. Production migration not applied.
