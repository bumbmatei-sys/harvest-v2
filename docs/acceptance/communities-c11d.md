# Communities C11d chat retention job

The worker-only command visits the channel and DM cleanup procedures in independent bounded loops. 0057 alone supports channel cleanup and health. Installing 0058 adds the DM loop. A missing optional function is detected from the database catalogue. Permission failures still fail the job. The failure recorder runs in a separate statement after a failed sweep.

`npm run communities:purge-chat` runs the sweep. `npm run communities:purge-chat -- check` exits nonzero when a run is overdue or a failure followed the last success. Both commands require `WORKER_DATABASE_URL` and check the connected role. The app database URL is unused. [Worker role](../setup/worker-role.md#community-chat-retention-command)
