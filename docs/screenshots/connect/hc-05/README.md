Each theme records six clean axe scans, actual tablet geometry, zero horizontal overflow and visible form controls at least 44×44px in `metrics-{light,dark}.json`. The journey also checks keyboard choice, independent unchecked defaults, validation correction, frozen in-flight choices, pending-only confirmation, exact replay, purpose withdrawal, erasure, recovery acknowledgement, same-origin protection, body bounds, no cookies/GET writes and no-store/no-referrer headers. Screenshots alone do not prove these runtime behaviors; the assertions do.
