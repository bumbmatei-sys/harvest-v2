# ADR 0002: Better Auth email code only

Accepted 2026-11-04. Use Better Auth's email OTP plugin and Drizzle adapter. Six digits, ten-minute expiry, five failed attempts, keyed SHA-256 storage, normalized-email database cooldown of 60 seconds before generation, and persistent HTTP rate limiting. The keyed hash resists offline enumeration of low-entropy codes after a database-only leak. Reject all non-sign-in code purposes. Expose no password, OAuth or code-reading endpoints. Resend delivery uses the existing sending domain via RESEND_API_KEY and EMAIL_FROM. Do not send emails as part of implementation or verification: unit/integration/browser tests mock the provider. Session creation writes an audit event. Delivery failures propagate through the request-scoped await policy and are visible to users without provider details.
