## Findings resolved before the reviewed head

- **P2 — Missing history warning without Navigation API:** the original implementation guarded traversal only through optional `window.navigation`, leaving same-document history transitions unguarded when that API was absent. A root-head bootstrap now installs the native history listener before Next hydration and offers a cancelable internal event to the active editor. Canceling that event suppresses the native event before Next handles it.
- **P2 — Fixed traversal distances restored/discarded the wrong destination:** the intermediate sentinel assumed `+1` restoration and `-2` discard. The final implementation removes those assumptions, records the actual attempted destination, restores the saved editor URL/state synchronously, and uses full-document navigation to the recorded URL only after explicit Leave. Cancel preserves the mounted draft. Same-path/hash traversal remains allowed. The documented compatibility tradeoff is that this fallback replaces the forward history branch; exact history-stack preservation is not claimed. This is acceptable within the stated compatibility behavior.
- **P2 — Listener ordering defeated the component-level fallback in Next:** after the source-only acceptance at `59ca121`, author browser execution found that Next could synchronously unmount the editor before its later listener ran. This was not detected by the earlier independent source review. The corrected root-head bridge is installed before hydration and dispatches `harvest-before-history`; it calls `stopImmediatePropagation` on the native event only when an active dirty editor cancels the internal event. Clean navigation and pages without an editor pass through. `useLayoutEffect` keeps the dirty/busy ref current before user interaction. The bridge contains no user interpolation, storage, request, tracking or URL parameters; its global flag makes installation idempotent. Author runtime evidence below supports the ordering correction; the reviewer did not independently execute a browser.

The complete final correction adds the bridge/root-head inclusion, changes the editor listener/ref timing, improves wrapping for plain headings/card text using `overflow-wrap:anywhere` and `min-w-0`, adjusts test setup to real client navigations, and clarifies acceptance. It changes no SQL, data contract or permission.
